# 手机端与上线测试指南

## iOS 微信

1. 打开前端公网链接。
2. 登录居民或游客账号，确认没有后台入口。
3. 检查首页、安置点、现场上报和底部 Tab 是否无横向滚动。
4. 点击“允许语音”，再点击预警卡片“播放”。
5. 如首次播放被拦截，应看到“请再点一次播放按钮以激活语音”或“请先点击页面任意位置，再使用语音播报”。
6. 提交一条现场上报，确认风险地图出现事件点。

## Android Chrome

1. 登录居民或游客账号，检查首页预警、风险等级、安置点和语音按钮。
2. 进入 AI 助手，提问“暴雨来了怎么办”，确认有 loading 和后备模型提示能力。
3. 进入风险地图，点击风险点，确认显示最近安置点。
4. 使用管理账号登录，进入后台推送预警。
5. 回到居民/游客首页，确认出现站内消息或最新预警横幅。

## 权限测试

1. 未登录访问 `/app` 应回到登录页。
2. 居民/游客直接访问 `/admin` 应回到 `/app`。
3. 未登录调用写接口应返回 401。
4. 居民/游客调用管理写接口应返回 403。
5. 区县管理员只能看到和处置本区县事件。
6. 社区/村部干部不可创建新预警，只能转发上级预警和处置本社区事件。

## 地图瓦片

默认使用天地图：

```text
https://t{s}.tianditu.gov.cn/vec_w/wmts?...&tk=VITE_TIANDITU_KEY
https://t{s}.tianditu.gov.cn/cva_w/wmts?...&tk=VITE_TIANDITU_KEY
```

如果未配置 `VITE_TIANDITU_KEY`，页面会显示提示，风险点和事件数据仍可通过面板查看。上线前必须在天地图控制台申请 Key 并配置到前端环境变量。

## CORS

如果手机公网访问出现 API 调用失败，检查后端环境变量：

```text
FRONTEND_ORIGIN=https://your-frontend-domain.com
```

该值必须等于实际前端公网域名。
